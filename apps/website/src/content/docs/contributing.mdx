## Getting started

Start by reading our [Contributing Guide](https://github.com/QwikDev/astro/blob/main/contributing.md). It includes how to get involved, and an in-depth section on how the integration works under the hood.

## Development setup

Clone the repository and install dependencies:

```bash
git clone https://github.com/QwikDev/astro.git
cd astro
pnpm install
```

## Reporting issues

If you find a bug or have a feature request, please [open an issue](https://github.com/QwikDev/astro/issues) on GitHub.

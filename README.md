## Quick Start

```bash
npm create @qwik.dev/astro@latest
```

Or add to an existing Astro project:

```bash
npx astro add @qwik.dev/astro
```

For full installation instructions, guides, and API reference, visit **[qwik.dev/astro](https://qwik.dev/astro)**.
